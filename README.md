# Deenora + Слово

Отдельная копия [Deenora](https://nazirka09-ui.github.io/deenora-web/).
Исходные репозитории `deenora-web` и `speedread` не изменяются.

Сайт: https://nazirka09-ui.github.io/deenora-slovo/

В разделах «Сира Пророка», «Расскажи мне об исламе» и «Хадисы»,
когда открыт большой текст, справа сверху есть кнопка «По словам».
Она включает спокойное чтение по одному слову: скорость, размер,
полный экран и фоновые звуки. «←» возвращает к тексту.
